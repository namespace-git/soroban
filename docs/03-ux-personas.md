# UX の物差し — ペルソナと「揃っているか」の見方

画面を足す・直すときに、**同じことをやるのに手順や見た目が違う**状態を作らないための物差し。
実装の決まりは `CLAUDE.md` の「UI の優先順位」と `src/renderer/style.css` 末尾の規約。ここはその**使い方**を書く。

## 2. 揃っているかの見方（レビューの質問）

新しい画面・機能を入れるとき、この 7 つを自分に聞く。

1. **同じ行為は同じ手順か** — タグ・メモ・削除・詳細を開く・絞り込む・並び替える・書き出す。
   ある画面だけ 2 クリック多い、ある画面だけダイアログ、は不可。
2. **同じものは同じ見た目か** — 状態ラベルの色、金額の書式（`−¥268`）、日付（`09/24`）、件数（`n 件 ・ 合計 ¥x`）。
3. **行をクリックしたら何が出るか、予測できるか** — その画面の中で一貫していて、他の画面とも近いか。
4. **空のときに何が出るか** — 「〈対象〉がまだありません」＋次の一歩のヒント。文言の型を外さない。
5. **消すときに同じ重さか** — 見出しは「〈名前〉を削除しますか？」、日付や金額は本文へ、戻せない操作は赤。
6. **直したものが他の画面にすぐ効くか** — 変更したら `changed()`。片方だけ古い数字が残らないこと。
7. **キーボードだけで届くか** — 押せるものは Tab で届き、Enter で押せる。閉じるは Esc。

## 3. 文言の型

| 場面 | 型 | 例 |
|---|---|---|
| 空（まだ無い） | `〈対象〉がまだありません` ＋ヒント1行 | 経費がまだありません／上のボタンから登録してください |
| 空（絞り込みの結果） | `検索条件に一致する〈対象〉がありません` | 検索条件に一致する在庫がありません |
| 消す確認 | 見出し `「〈名前〉」を削除しますか？`／本文に日付・金額／赤 | 「【Z080-1】…」を削除しますか？ |
| 済んだ | `〈したこと〉ました` | 保存しました／紐付けました／書き出しました |
| できない | `〈何が〉〈どうして〉` ＋ 次の一歩 | 型番が一致する在庫はありませんでした |
| 入力の誤り | `〈項目〉を〈どう〉入力してください` | 送料は 0 以上の整数で入力してください |

単位は **件**（もの）と **点**（在庫の個数）だけ。「個」「本」は使わない。
**在庫の数は必ず「点」**（一覧の件数表示も含む）。販売・仕入・経費は「件」。
